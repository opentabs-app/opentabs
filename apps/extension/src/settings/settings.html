OpenTabs.

Everything here lives in your browser. Nothing is sent to a server unless you turn on Sync — and then it is sealed before it goes.

Four groups are on by default, deliberately — a new tab you open fifty times a day should be calm. Turn on as much as you like.

A topic is a name and some sources. Type any subject — the query sources cover it with no setup. Seven ship as examples; there is no difference between those and one you invent.

One card per thing you watch. Dates are a rolling window by default, so a saved search stays current instead of freezing on the day you made it.

Subscribe with the secret iCal address your calendar gives you. Works with Google, Outlook, iCloud, Fastmail, Proton, Notion, Linear and Cal.com — one mechanism, no sign-in.

That address is a password in URL form: anyone holding it can read your calendar. It is stored on this device only, and is left out of exports unless you tick the box.

Fetches the first calendar and prints the raw date lines beside how they were read. If the times look wrong, this is what says why. 

      

      

        Where do I find that address?
        
    
          
  • Google — Settings → your calendar → “Secret address in iCal format”.
    • 
          
  • Outlook / Microsoft 365 — Settings → Calendar → Shared calendars → Publish, then copy the ICS link.
    • 
          
  • Apple iCloud — right-click the calendar → Share Calendar → Public Calendar, then copy the link.
    • 
          
  • Notion / Linear / Cal.com — look for “Subscribe” or “iCal” in the calendar view.
    •

        storage.sync already follows one browser signed into one account.
        This crosses the line that cannot: Chrome to Firefox, work profile to personal,
        a laptop signed into nothing. Your settings, to-dos, Focus list, calendar
        addresses and API keys are sealed on this device before they leave it — the
        relay holds ciphertext and a public key, and nothing that can read them.

            ciphertext and a public key, and no name, address or account. To rest them
            somewhere else instead, run opensync relay on a machine of your
            own and put its address here.
