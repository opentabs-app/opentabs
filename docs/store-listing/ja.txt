===== OVERVIEW (CHROME) (locale: ja) =====
OpenTabsは、プライバシーを最優先した新しいタブのワークスペースです。閲覧履歴をリモートサービスに送信することなく、開いているタブの確認、整理、操作ができます。タブのグループ化と並べ替えは拡張機能内でローカルに実行されるため、タブの情報はブラウザ内にとどまります。

機能

• 複数のブラウザウィンドウで開いているタブを1か所で表示
• サイトごとにタブを自動でグループ化
• ダッシュボードから直接タブを閉じる
• 重複したページを検出して閉じる
• 複数のウィンドウのタブを統合
• タスクとネストしたステップで今日のフォーカスを記録
• ページを再読み込みしてもタスクの進捗を保持
• よく使うウェブアプリを起動
• 天気、カレンダー、ブックマーク、マーケット、トピックなどの設定可能なカードを追加
• ポータブルな設定文字列で設定をエクスポート・復元

コアのタブ管理とフォーカス機能はアカウントなしで利用できます。アカウントが必要になるのは、共有パックの公開や「いいね」といったコミュニティ機能を使う場合のみです。

OpenTabsは無料でオープンソースです。タブの整理はローカル処理、オプションの情報カードはバックグラウンド更新という設計により、高速な新しいタブ体験を実現しています。

Chromiumベースのブラウザ、および Firefox で利用できます。本テストでは Microsoft Edge の Chromiumビルドで動作を確認しました。

GitHub: https://github.com/opentabs-app/OpenTabs/
