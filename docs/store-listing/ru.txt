===== OVERVIEW (CHROME) (locale: ru) =====
OpenTabs — это ориентированное на приватность рабочее пространство новой вкладки, которое помогает видеть, упорядочивать и управлять открытыми вкладками, не отправляя данные о вашей активности в браузере на удалённый сервер. Группировка и ранжирование вкладок выполняются локально в расширении, поэтому ваши вкладки остаются в вашем браузере.

ВОЗМОЖНОСТИ

• Просматривайте открытые вкладки из нескольких окон браузера в одном месте
• Автоматически группируйте вкладки по сайтам
• Закрывайте вкладки прямо из дашборда
• Находите и закрывайте дублирующиеся страницы
• Объединяйте вкладки из нескольких окон
• Фиксируйте дневной фокус с помощью задач и вложенных шагов
• Сохраняйте прогресс задач после обновления страницы
• Запускайте часто используемые веб-приложения
• Добавляйте настраиваемые карточки погоды, календарей, закладок, рынков, тем и другого
• Экспортируйте и восстанавливайте конфигурацию с помощью переносимой строки конфигурации

Основное управление вкладками и функции Focus работают без аккаунта. Аккаунт нужен только для действий сообщества, таких как публикация или лайк общих наборов (packs).

OpenTabs бесплатен и имеет открытый исходный код. Он создан для быстрой работы с новой вкладкой: обработка данных для организации вкладок выполняется локально, а фоновые обновления касаются только опциональных информационных карточек.

Доступно для браузеров на основе Chromium и для Firefox. Тестирование проводилось на сборке Chromium в Microsoft Edge.

GitHub: https://github.com/opentabs-app/OpenTabs/
