===== OVERVIEW (CHROME) (locale: ko) =====
OpenTabs는 브라우징 활동을 원격 서버로 전송하지 않고도 열려 있는 탭을 확인, 정리, 관리할 수 있도록 도와주는 개인정보 보호 중심의 새 탭 워크스페이스입니다. 탭 그룹화와 정렬은 확장 프로그램 내에서 로컬로 실행되므로 탭 정보는 브라우저 안에 그대로 유지됩니다.

기능

• 여러 브라우저 창에서 열린 탭을 한곳에서 확인
• 사이트별로 탭 자동 그룹화
• 대시보드에서 바로 탭 닫기
• 중복 페이지 찾아서 닫기
• 여러 창의 탭 병합
• 작업과 하위 단계로 오늘의 포커스 기록
• 페이지를 새로고침해도 작업 진행 상황 유지
• 자주 사용하는 웹 앱 실행
• 날씨, 캘린더, 북마크, 시세, 토픽 등 구성 가능한 카드 추가
• 이동 가능한 설정 문자열로 구성 내보내기 및 복원

핵심 탭 관리와 포커스 기능은 계정 없이 사용할 수 있습니다. 계정은 공유 팩 게시나 좋아요 같은 커뮤니티 활동에만 필요합니다.

OpenTabs는 무료이며 오픈소스입니다. 탭 정리는 로컬에서 처리하고 선택적 정보 카드는 백그라운드에서 업데이트하는 방식으로, 빠른 새 탭 경험을 제공하도록 설계되었습니다.

Chromium 기반 브라우저 및 Firefox에서 사용할 수 있습니다. 이번 테스트는 Microsoft Edge의 Chromium 빌드에서 확인했습니다.

GitHub: https://github.com/opentabs-app/OpenTabs/
